Markdown 与代码调试

Markdown 是一种用简单符号给文字排版的格式。比如，行首加上 # ，这行文字就会变成标题。

下面可以查写法、看效果，也可以复制示例到练习网页里试。第一次使用，先完成这四步。

  1. 打开练习网页

    点右上角“打开练习网页”。左边是文件列表，中间是编辑区；点击文件名，就能打开文件。

  2. 新建一份笔记

    点左上角“文件 → 新建 Markdown 文件”，输入 我的大学第一周.md，按回车。.md 是 Markdown 文件的后缀，要保留它。

  3. 输入第一行文字

    # 我的大学第一周

    # 用英文符号，后面按一次空格，再输入标题。

  4. 打开右侧预览

    点编辑区右上角的“打开侧边预览”按钮。也可以先按 Ctrl + K，松开后再按 V。左边显示写法，右边显示排版结果；修改文字后，预览会跟着更新。

预览中出现大标题，就可以继续往下写了。结束练习时，按保存与下载里的步骤把文件下载到电脑。

保存与下载

网页里的练习会保存在当前浏览器中。要交作业、换电脑或留一份备份，需要下载文件。

只下载这份笔记

  1. 在编辑区打开要保存的 .md 文件。
  2. 点“文件 → 下载当前文件”。
  3. 到浏览器的下载记录或电脑的“下载”文件夹中找到它。

下载到的是 Markdown 源文件。以后可以用 VS Code 打开，继续修改。

把图片一起带走

如果笔记用了本地图片，点“文件 → 下载整个练习目录（ZIP）”。解压后保留 .md 文件和图片文件夹的位置，图片路径才能继续使用。

只下载 .md 文件不会把图片装进去。换电脑后图片打不开，先检查图片文件是否也带过去了。

继续编辑电脑上的文件

点“文件 → 导入本地文件…”，选择 .md 文件。如果有配套图片，用“导入本地文件夹…”一起导入。

代码调试

调试时，可以让程序停在指定行，查看变量，再让它一行一行往下执行。这样就能看到结果是从哪一步开始不对的。

先认识三个操作

断点
告诉程序在哪里暂停。点击代码行左侧、行号旁边的空白处，会出现一个红点；再点一次就取消。
变量
程序当前保存的值。暂停后看左侧“变量”，就能知道 i、total 等变量现在是多少。
单步
只往下执行一步。按 F10 后，黄色位置会移动，变量也可能改变。

黄色行表示下一步要执行的代码。如果黄色行是 total = total + i，这一行的加法还没有执行。

例一：少加了哪个数

打开左侧 debug 文件夹里的 01_循环边界.py。它要计算 1 + 2 + 3 + 4 + 5，正确结果是 15，但原程序算出的是 10。

def sum_to(n):
    total = 0
    for i in range(1, n):
        total = total + i
    return total
  1. 在 total = total + i 左边设断点。
  2. 按 F5 启动。第一次需要加载 Python，等程序停在红点所在行。
  3. 展开左侧“变量”，找到 n、i、total。第一次停下时，它们分别是 5、1、0。
  4. 按一次 F10，加法执行完，total 变成 1。
  5. 继续单步，观察 i 有没有取到 5，以及 total 最后是多少。

逐步查看执行记录

下面记录了这段函数的实际执行过程。点“下一步”看变量变化；要亲自设断点，在练习网页里操作。

查看原因和修改方法
range(1, n) 包含 1，不包含 n。n 等于 5 时，i 只会取到 1、2、3、4。
for i in range(1, n + 1):
    total = total + i
先按 Shift + F5 停止，再改代码、重新按 F5。调试控制台应显示“计算结果：15”，并且不再出现末尾的断言报错。
还可以把 number 改成 1，检查结果是否为 1；改成 6，检查结果是否为 21。文件末尾的“期望结果”和断言中的数值也要一起改。


例二：两个参数传反了
打开 debug/03_函数参数.py。买 3 本单价 12 元的书，再减 5 元优惠券，应付 31 元，原程序却算出 -31。
def pay_after_coupon(total, coupon):
    payment = total - coupon
    return payment

def checkout(price, count, coupon):
    subtotal = price * count
    result = pay_after_coupon(coupon, subtotal)
    return result


  1. 在 result = pay_after_coupon(coupon, subtotal) 这一行设断点，按 F5。
  2. 暂停后，确认 subtotal 是 36，coupon 是 5。
  3. 按 Alt + F11 进入 pay_after_coupon。网页使用这个组合键，以免单独按 F11 让浏览器进入全屏。
  4. 在函数里面看参数：total 变成了 5，coupon 变成了 36。参数按位置传入，所以减法变成了 5 − 36。


查看修改方法
result = pay_after_coupon(subtotal, coupon)
把总价放前面、优惠券金额放后面。停止调试后修改，再重新运行，结果应为 31。


调试时常用的按键
F5
启动调试；暂停后继续运行到下一个断点。
F10
执行当前行。遇到函数调用时，执行完整个函数再停下。
Alt + F11
网页中的单步进入。遇到函数调用时，进入函数里面。
Shift + F11
执行完当前函数，回到调用它的位置。
Shift + F5
停止本次调试。改完代码后，重新按 F5 启动。
有些笔记本需要同时按住 Fn。也可以把鼠标放到调试工具栏图标上，看到名称后点击对应按钮。




常见问题


写了 #，为什么没有变成标题？
确认使用英文 #，它在行首，后面有空格。然后看右侧预览；左侧编辑区本来就会保留这些符号。


整个后半篇都变成了代码，怎么办？
往前找最近一处代码块，检查有没有在结束位置另起一行，写上三个反引号。开始和结束要配对。


图片只显示文件名，怎么办？
先在左侧找到图片，确认它确实存在。再从当前 .md 文件所在的文件夹出发检查路径。文件名、后缀和大小写都要一致，路径里的斜线用 /。


复制到其他网站后，效果为什么不同？
标题、列表等基本写法通常通用。表格、公式、任务列表和 Mermaid 属于常见扩展，各个平台支持的范围可能不同。本文的效果以这次练习网页为准。


修改代码后，为什么调试里还是旧结果？
先停止当前调试，再重新启动。已经开始的一次运行不会因为你修改了源码就自动从头运行。


断点没有停住，先检查哪里？
确认打开的是 .py 文件，红点设在会执行到的代码行上，例如加法或函数调用。不要设在空行或注释上。再按 F5 启动；程序如果已经结束，需要重新启动。

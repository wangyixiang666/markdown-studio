## 一点思考

当文件放进子目录，相对路径也会跟着变化。`..` 表示上一级目录，`.` 表示当前目录。

| 路径 | 含义 |
| :--- | :--- |
| `../assets/山间日出.svg` | 上一级目录中的图片 |
| `./元数据示例.md` | 当前目录中的文档 |

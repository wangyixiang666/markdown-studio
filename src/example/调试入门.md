# 看见程序怎样运行

程序出了错，先别急着重写。让它停下来，看一眼变量，再走一步。

左侧 `debug` 文件夹里有五份很短的 Python 程序。它们都有一个有意留下的错误，可以直接在这里运行和调试，不需要安装 Python。

## 先试一次

1. 打开 [01_循环边界.py](./debug/01_循环边界.py)。
2. 按 **F5**，或者点击编辑器右上角的绿色三角形。
3. 程序会停在第一条可执行语句。黄色高亮表示“下一条将要执行的语句”。
4. 按 **F10** 执行下一步，在左侧“变量”中观察数值。
5. 遇到 `answer = sum_to(number)` 时，按 **Alt+F11** 进入函数。
6. 一步步看循环执行，找出 `total` 为什么等于 10。

第一次启动需要加载 Python 运行环境。看见“Python 已就绪”后即可操作。

## 认识几个按钮

| 操作 | 快捷键 | 什么时候用 |
| :--- | :--- | :--- |
| 开始 / 继续 | F5 | 跑到下一个断点或异常 |
| 切换断点 | F9 | 在当前行暂停，也可点击行号左侧 |
| 单步跳过 | F10 | 执行一行，把函数调用当成一步 |
| 单步进入 | Alt+F11 | 进入自己写的函数（桌面版通常为 F11） |
| 单步跳出 | Shift+F11 | 跑完当前函数，回到调用它的位置 |
| 重新开始 | Ctrl+Shift+F5 | 修改代码后重新运行 |
| 停止 | Shift+F5 | 结束本次运行 |

如果浏览器占用了功能键，就点击上方浮动调试工具栏中的同名按钮。

## 练习一：少算了一个数

[打开程序](./debug/01_循环边界.py)

**任务：** 算出 `1 + 2 + 3 + 4 + 5`。

**先观察：** 在 `total = total + i` 这一行设断点。按 F5，每次停下时记录 `i` 和 `total`。

| 暂停时的 i | 当前 total | 执行这一行后 total |
| ---: | ---: | ---: |
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |
| 4 | 6 | 10 |

**想一想：** 为什么看不到 `i = 5`？`range(1, n)` 包含右端的 `n` 吗？

**再验证：** 修好后，把 `number` 改成 1 或 10，结果应分别为 1 和 55。记得相应修改最后的期望值。

## 练习二：恰好等于怎么办

[打开程序](./debug/02_条件边界.py)

**任务：** 满 100 元免运费，未满则收 8 元。

在 `if amount > 100:` 设断点，观察输入 99、100、101 时程序走哪一条分支。

试着右键单击断点，选择编辑断点，把条件写成 `amount == 100`。再次运行，只在这个边界情况停下来。

**想一想：** “大于 100”和“达到 100”有什么区别？

## 练习三：参数去了哪里

[打开程序](./debug/03_函数参数.py)

**任务：** 3 本书，每本 12 元，再减去 5 元优惠券，应付 31 元。

1. 在 `result = pay_after_coupon(coupon, subtotal)` 设断点。
2. 按 Alt+F11 进入函数。
3. 对比调用前的 `subtotal`、`coupon` 与函数里的 `total`、`coupon`。
4. 在“调用堆栈”中点击 `checkout`，再点击 `pay_after_coupon`，查看不同函数里的局部变量。
5. 按 Shift+F11 回到调用者，观察返回值。

**想一想：** 函数里的参数值，来自实参的名字，还是传入的顺序？

## 练习四：两个名字，一份列表

[打开程序](./debug/04_列表共享.py)

**任务：** 给新名单加入“小陈”，保留原名单。

在 `updated.append("小陈")` 设断点，展开变量中的两个列表。执行一步后再比较它们。

## 练习五：读懂报错

[打开程序](./debug/05_越界异常.py)

**任务：** 读取第三位同学的分数。

保持“断点”区域中的“未捕获的异常”勾选。开始调试，再按 F5，程序会在发生 `IndexError` 的地方停下来。

查看 `student_number`、`index` 和 `len(scores)`。在调试控制台分别试试 `scores[0]`、`scores[1]`、`scores[2]`。

**想一想：** 现实中的“第一个”，对应 Python 里的哪个下标？

## 再多试一点

- **监视表达式：** 把 `total`、`i`、`total + i` 加进监视，每次暂停时比较它们。在变量尚未定义时看到 `NameError` 是正常的。
- **临时改变量：** 暂停时，在变量面板双击一个数值，输入新的值。它只改变这次运行，源码不会自动修改。
- **记录日志：** 在行号左侧添加日志点，输入 `此时 i={i}，total={total}`。程序继续运行，在调试控制台留下记录。
- **命中次数：** 右键循环中的断点，把命中次数设成 `3`，只在第三次经过时暂停。
- **修改后重跑：** 保存源码后重新开始调试。已经开始的一次运行使用启动时的源码快照。
